プライバシーポリシー

最終更新日: 2026-10-02

本アプリ「楽太郎 for opencode」（以下、本アプリ）は、利用者本人のGoogleアカウントに紐づく情報を、本人の依頼に基づく連絡・スケジュール管理・ファイル管理の補助のために利用します。

取得する情報

  • 利用者本人が入力・共有した予定、タスク、画像などの情報
  • Google API を通じて取得するカレンダー、メール、ドライブ、タスクの情報（本人が許可した範囲）

利用目的

  • 毎朝の予定・タスクのまとめ通知
  • 依頼に応じたファイルの整理・アップロード
  • カレンダー・メール・タスク情報の閲覧補助

第三者提供

取得した情報は上記の目的のために必要な範囲でのみ使用し、第三者へ販売・提供しません。

Googleユーザーデータの利用

本アプリがGoogle APIから取得した情報の利用は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。取得したGoogleユーザーデータは、本ポリシーに記載した目的以外には使用せず、広告目的で使用・転送することはありません。

データの保管と削除

データは利用者本人の端末内にのみ保存されます。削除を希望する場合は、共有の場を通じてご連絡ください。

お問い合わせ

本アプリのプライバシーに関するお問い合わせは、共有の場を通じてご連絡ください。
